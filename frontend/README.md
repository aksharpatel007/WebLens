# Web Auditor Frontend

This is the React frontend for **Web Auditor**, built with Vite, TypeScript, and React. It provides a modern, interactive dashboard to run, monitor, and review website audits in real-time.

## Features

- **Real-time Monitoring**: Connects to the Web Auditor Playwright engine to show live audit progress.
- **Modern Dashboard**: Clean, responsive interface for reviewing SEO, Accessibility, and Performance findings.
- **Fast and Lightweight**: Built on top of Vite for rapid development and optimized production builds.

## Getting Started

To run the frontend individually:

```bash
cd frontend
npm install
npm run dev
```

The application will be accessible at `http://localhost:5173`.

> **Note**: To run both the backend engine and frontend simultaneously, use `npm run dev` from the project root.
